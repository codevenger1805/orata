# Orata 🎙️

🌐 **[Try Orata Live](https://orata-blush.vercel.app/)**

> **Think fast. Speak clearly. Try not to say “umm” 47 times.**

Orata is an AI speaking coach that helps you practice **Impromptu, Interview & Communication** skills without the awkwardness of talking to yourself.

### How it works
**Pick a mode → Spin a challenge → Speak → Get feedback → Try again.**

### What you get
- 🎯 Realistic speaking challenges
- 🎙️ Browser-based voice practice
- 📊 Feedback on clarity, structure, fluency & conciseness
- 🔁 Repeat attempts to actually improve
- 💡 Helpful topic insights when you get stuck

### Built with
**Next.js · React · TypeScript · Tailwind CSS · Prisma · PostgreSQL · Web Speech API · Vercel**

No account. No overthinking. Just **spin, speak, improve.**
